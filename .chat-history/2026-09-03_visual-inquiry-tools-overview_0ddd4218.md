**Ivan Aaen:**
Associate Professor, Department of Computer Science, Aalborg University. Research areas: software development, software process, agile development, software innovation, SaaS value creation, mobile systems, user-centred design.
Main work: `Essence: Team-Based Software Innovation` (2012, http://essence.dk). Thesis: teams need support after idea generation — to select, combine, and mature ideas into practice. Innovation is non-linear. Methodology is structure-based, not process-based, with three structures: Views, Roles, Visions. Designed for agile contexts where the problem situation talks back during solution building.

**Visual inquiry tools:**
Visual charts used for externalization and joint inquiry. Examples: Business Model Canvas, Lean Canvas, concept maps, mind maps, rich pictures, sketches. Function: make assumptions explicit, foster understanding, discussion, creativity, and analysis, typically via post-its on a large shared surface.

**Problem Solution Canvas:**
A type of visual inquiry tool. Separates problem space from solution space on one page to prevent premature solution fixation. Typical blocks: problem / stakeholders / context / needs on one side; solution ideas / value propositions / assumptions to test on the other. Used iteratively: update problem understanding as solutions are prototyped.
