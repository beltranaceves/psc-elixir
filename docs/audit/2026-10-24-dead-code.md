# PSC dead code audit

**Date:** 2026-10-24
**Scope:** application code in `lib/`, `test/`, `assets/js/`, `config/`, `priv/`, `scripts/`
**Method:** static scan of every public `def` and its call sites (alias/import aware), `mix compile --warnings-as-errors`, `mix xref callers MODULE`, and targeted `grep` verification. Framework callbacks, router atoms, dynamic behaviour dispatch, and docs/history were excluded as false positives.
**Changes made:** none. This is an audit only.

## Summary

| Category | Findings |
|---|---:|
| Confirmed dead public functions/modules in application code | 21 |
| Production-unused but test-only APIs | 7 |
| Unused SaladUI Elixir modules (library surface) | 30 modules / 6,395 lines |
| Unused SaladUI JS imports / files | 12 imports / ~3.9k lines; 3 files never imported |
| Unused Ecto associations (low priority) | 8 |
| Dead config / inert wiring | 2 items |
| Stray repo artifacts | 2 |

The application-level dead code is small (roughly 200 lines), but concentrated in `Psc.Canvas`, `Psc.Notes`, `Psc.Agent`, and a few generated Phoenix helpers. The largest removable surface is the unused SaladUI component library and its JS.

## 3. Unused SaladUI library surface

The app uses 10 component families: `Badge`, `Button`, `Checkbox`, `Dialog`, `Form`, `Helpers`, `Input`, `Label`, `Textarea`, `Tooltip` (plus `Icon` transitively through `Form`). The other local SaladUI modules are not reachable from any app template or module.

**30 unreachable Elixir modules — 6,395 lines:**

`Accordion`, `Alert`, `AlertDialog`, `Avatar`, `Breadcrumb`, `Card`, `Chart`, `Collapsible`, `Command`, `DropdownMenu`, `HoverCard`, `LiveView`, `Menu`, `Pagination`, `Popover`, `Progress`, `RadioGroup`, `ScrollArea`, `Select`, `Separator`, `Sheet`, `Sidebar`, `Skeleton`, `Slider`, `Switch`, `Table`, `Tabs`, `Toast`, `Toggle`, `ToggleGroup`.

**Unused JS imports in `app.js` (~3.9k lines):**

`select.js` (583), `tabs.js` (199), `radio_group.js` (264), `popover.js` (156), `hover-card.js` (205), `collapsible.js` (107), `accordion.js` (289), `slider.js` (324), `switch.js` (113), `dropdown_menu.js` (258), `menu.js` (357, transitive), `toast.js` (954), `toast-flash.js` (63).

**Never imported at all:** `chart.js` (98), `command.js` (143). `menu.js` is imported only by the unused `dropdown_menu.js`.

**Toast note:** `toast.js` / `toast-flash.js` are imported, but the app never renders `<.toaster>`; the Elixir `Toast` module is unused. The `ToastFlashBridge` therefore has no element to act on.

**Caveat:** these are generated/vendored SaladUI files (`feat: add saladUI components`), not hand-written app code. If you expect to use more SaladUI components later, keep them; if bundle size and dead surface matter, remove the no-arg `ui.ex` clause, the 30 modules, and the unused `app.js` imports. Do this as a separate commit from app-code cleanup.

   - The only reader is `Psc.Agent.enabled?/0`, which has no callers.
   - `Psc.Agent.enabled?/1` checks the user's key/model only, so the deployment-level switch has no effect.

   - `periodic_measurements/0` returns `[]`.
   - The supervisor runs but measures nothing. Keep as future scaffolding or remove.

## 9. Recommended removal order

1. **Zero-risk app deletes:** items 1–18 and 22–25 in section 1. Run `mix.bat verify` after the batch.
2. **Page/auth cleanup:** `PageHTML`, the `_action` clause, the magic-link delivery chain (section 2) with test updates.
3. **Test cleanup:** unused fixtures and the unused alias (section 6).
4. **Library trim (separate commit):** remove the no-arg `ui.ex` clause, the 30 unreachable UI modules, and the unused `app.js` imports. Rebuild assets and run the E2E suite.
5. **Config decision:** wire or remove `:agent_enabled`; remove inert telemetry or add a reporter.
6. **Associations:** optional; only if you want the schemas to state exactly what the code uses.
